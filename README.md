# CIT300 Assignment 2 – Data Structure and Graph Performance Analyzer

## Project Overview

This Java console-based application demonstrates fundamental data structures, searching algorithms, graph traversal, and algorithmic performance comparison through an integrated, menu-driven system.

## Main Features

- **Array:** Insert, delete, search, and display.
- **Stack:** Push, pop, peek, and display, including empty-stack handling.
- **Queue:** Enqueue, dequeue, show front, and display, including empty-queue handling.
- **Linked List:** Insert, delete, search, and display.
- **Searching:** Linear Search and Binary Search.
- **Graph:** Add vertices and edges, display the graph, search vertices, and perform BFS and DFS traversals.
- **Performance Comparison:** Compare searching algorithms using the measurements provided by the application.
- **Integrated Console Menu:** Navigate between components and handle invalid or empty operations.

## How to Run the Project

1. Install the Java Development Kit (JDK).
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project folder.
4. Compile the source files:

   `javac -d out src/*.java`

5. Run the application:

   `java -cp out Main`

## Searching Algorithm Complexity

- **Linear Search:** O(n) in the worst case.
- **Binary Search:** O(log n) in the worst case, provided the input is sorted.
