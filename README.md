# CIT300 Assignment 2 – Student Record Management System

## Project Overview
This project is a Java console-based application developed for the CIT300 group assignment. It demonstrates data structures and searching algorithms through a menu-driven system.

## Features
- Array Operations
- Stack Operations
- Queue Operations
- Linked List Operations
- Linear Search and Binary Search
- Graph Operations using Breadth-First Search (BFS) and Depth-First Search (DFS)
- Performance Comparison of Searching Algorithms
- Menu-driven user interface
- Input validation

## Technologies Used
- Java
- Visual Studio Code
- Git and GitHub

## How to Run the Project

1. Install the Java JDK.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project folder.
4. Compile the Java files:

   `javac -d out src/*.java`

5. Run the application:

   `java -cp out Main`

## Searching Algorithm Complexity
- Linear Search: O(n)
- Binary Search: O(log n) for the search operation on sorted data.
- Binary Search requires sorted data before searching.

## Conclusion
This project demonstrates the implementation and integration of fundamental data structures and searching algorithms in Java. It also provides a basic performance comparison between Linear Search and Binary Search.
